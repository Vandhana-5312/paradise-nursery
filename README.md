# Paradise Nursery

Paradise Nursery is a React plant shopping application where users can browse plants, add them to cart, and manage quantities.

## Features
- Landing page with company name and Get Started button
- About Us page
- Product listing page with categories
- Shopping cart with add, remove and update quantity
- Redux Toolkit for state management

## How to run
npm install
npm run dev

## Technologies
React, Vite, Redux Toolkit, CSS
